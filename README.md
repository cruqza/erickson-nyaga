# Portfolio — erickson-nyaga.vercel.app

One-page portfolio for Erickson Mugendi Nyaga (data analyst / data scientist), built with Astro and deployed on Vercel.

Sections run in skim order for a recruiter: name + positioning headline → three project cards (Flagship first) → skills strip → About → contact strip (email + GitHub only).

## Local development

```bash
npm install
npm run dev      # http://localhost:4321
```

## Production build

```bash
npm run build    # outputs to dist/
```

## Deployment

Connected to Vercel via the GitHub Git integration — every push to `main` auto-deploys to https://erickson-nyaga.vercel.app.
