# ADR 0002 — Project selection and grouping

- **Date:** 2026-10-31
- **Status:** Accepted
- **Context:** Six projects span three disciplines. Showing them all equally
  would dilute the signal a recruiter gets in the ~7 seconds they scan a page.
  The goal is to lead with the strongest single demonstration of each discipline,
  then show the supporting work.
- **Decision:** Group projects by work persona (Analytics, Machine Learning,
  Data Engineering & Pipelines) and feature the strongest project in each group.
  The "Flagship — ML" highlights the churn pipeline; supporting projects live in
  the "All projects" section.
- **Consequences:**
  - Recruiters see one clear brand per discipline instead of six equal cards.
  - The featured grid stays tight while the full history stays one click away.
  - Project order is stable and intentional; a hire can follow the persona trail.
