# ADR 0003 — Recruiter-first card structure

- **Date:** 2026-10-31
- **Status:** Accepted
- **Context:** Standard project cards put the blurb first, which buries the
  impact a recruiter actually wants before clicking through.
- **Decision:** Each featured card presents, top to bottom: a tagged title, an
  industry line, a metrics line, the one-line blurb, an "outcome" line, then the
  links. The outcome line is the part the recruiter reads last and remembers
  first, so it gets its own callout.
- **Consequences:**
  - A recruiter can answer "what did they do?" and "what did it deliver?" from
    the card alone, with no clicking.
  - The same structure scales to future projects without redesigning the page.
